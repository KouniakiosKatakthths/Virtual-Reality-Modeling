# Virtual Reality Modeling
For the VRM laboratory the godot game engine is been used. For uploading large files to github, Git Large File Storage (GLFS) is also used.

## Lab 2
For this lab the interaction that has been implemented is the creation of a campfire. The player can move around using the **AWSD** keyboard keys and look around using the mouse. To interact/pickup items the **E** key is used and to drop the item currently in hand the **F** button is used.

In Addition a simple UI has been implemented that shows the name of the item currently in the player's hand.

#### Campfire steps

1. **Rebuild the Campfire place**: The player needs to rearenge the stones of the campfire.
2. **Get tinder**: Tinder is needed at the base of the fire. There are two steps:
    * Destroy the barrel to get wood.
    * Pickup the tinder.
    * Place the tinder to the campfire.
3. **Get logs**: In the top of the campfire the player needs to place big logs. There are two logs in the map that the player needs to pickup and place at the campfire.
4. **Oil the wood**: After the wood is inside the campfire the player needs to get the oil bottle and spray the wood with it.
5. **Light the fire**: The player lights the fire using the lighter.

#### Actions
1. Rebuild Campfire
2. Destroy Barrel
3. Pickup tinder
4. Place tinder
5. Pickup Log
6. Place Log
7. Pickup Oil
8. Use Oil
9. Pickup Lighter
10. Light fire
